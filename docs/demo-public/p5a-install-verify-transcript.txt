$ agentcommit --help
Usage: agentcommit [options] [command]

Transactional safety for AI agents. Preview, commit, and safely roll back agent
changes.

Options:
  --version                    show version
  -h, --help                   display help for command

Commands:
  init                         initialize an AgentCommit workspace in the
                               current directory
  run [options] [command...]   run an agent command inside a protected session
  status                       show the current or latest session summary
  diff [path]                  show the session diff (text diff for text files,
                               metadata for binaries)
  commit                       accept the current session changes (this is not a
                               Git commit)
  rollback [options]           safely restore the workspace to the session start
                               state
  restore [options] <path...>  restore a single path from the session snapshot
  history                      list past sessions of this workspace
  show <id>                    show details of one historical session
  doctor [options]             read-only diagnosis of permissions, state
                               directory, sessions, and platform
  gc                           reserved cleanup command (disabled in 0.1 alpha)
  unlock [options]             remove a proven-stale workspace lock (requires
                               session id confirmation)
  resolve [options]            explicitly resolve a crashed-wrapper session
                               (interactive; evidence preserved)
  purge                        reserved full-cleanup command (disabled in 0.1
                               alpha)
  agent                        manage registered agent launch commands
  help [command]               display help for command
